## ✨ Sobre o projeto

Este não é apenas um site de casamento.

O objetivo é criar uma experiência digital premium, inspirada em marcas como Apple, Cartier e Dior, onde cada detalhe transmite elegância, emoção e personalidade.

O site foi pensado para reunir todas as informações do casamento em um único lugar, proporcionando uma navegação fluida, responsiva e agradável para todos os convidados.

---

## 🎯 Objetivos

* Apresentar nossa história
* Informar data, horário e local da cerimônia
* Disponibilizar mapa e rota
* Exibir contagem regressiva
* Compartilhar nossa galeria de fotos
* Disponibilizar lista de presentes
* Receber confirmações de presença (RSVP)
* Criar uma experiência visual inesquecível
